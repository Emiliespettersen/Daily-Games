# Daily-Games

### Spillene:
1. Fire på Rad
2. Hangman
3. Mineswiper
4. Number-matching
5. Ordgjetter

Disse spillene er basert på typiske 'daily games'

### Målet: 
Målet mitt er å legge alt inn i en nettside slik at det er bedre oversikt. Jeg ønsker også å ha en leaderboard og at man kan bli med i 'klubber' for å konkurere hvem som er best. F.eks på jobb, klassen, linjeforeningen osv.
